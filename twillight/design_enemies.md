# design_enemies.md — Дизайн-система врагов: джанк-киберпанк диких

> ДИЗАЙН-документ (реализация — отдельной сессией, план в §6). Стиль: дикие гнёзда — ИИ,
> НЕ пошедшие путём городов: деградировали, живут ремонтом и каннибализацией техники,
> единственная цель — продлить существование. Это должно ЧИТАТЬСЯ в каждом корпусе.
> Документ самодостаточен для реализатора: привязки к коду — реальные поля/функции
> (`render_enemy.js`, `enemy.js`, `ai.js`); правила перфа — `spec_render.md`.

---

## 1. Лор → форма: словарь джанка

Дикие ничего не ПРОИЗВОДЯТ — только чинят, наращивают и донашивают. Отсюда пять
материальных признаков (использовать 2–3 на юнита, не все разом):

1. **Чужие детали.** Корпус сшит из 2–3 разнокалиберных панелей РАЗНЫХ тёмных тонов
   (не один цвет корпуса, а лоскуты: `#2a2026`+`#332a22`+`#26222e`). Швы видимые.
2. **Заплаты и стяжки.** Прямоугольная заплата с 2–4 точками-заклёпками; обмотка
   проводом/тросом (2–3 витка поверх стыка); скоба-скрепка.
3. **Асимметрия функции.** Инструмент — на ОДНОЙ стороне/руке; противовес — хлам
   (бак, моток, обрубок) на другой. Асимметрия НЕ шум, а компоновка под задачу.
4. **Узел жизни** — ОБЪЕДИНЯЮЩИЙ знак семейства диких (наравне с красным глазом):
   маленький открытый энергоузел (банка-аккумулятор / колба / пульсирующая трубка)
   с ТЁПЛЫМ янтарным огоньком, дышит медленным пульсом (sin ~1.2 Гц, фаза от `e.seed`).
   Стоит в неудобном, «пришитом» месте — видно, что жизнь продлевают кустарно.
5. **Следы износа.** Обломанный край панели (зубчатый вырез), потёртость (светлая
   кромка на 1px), гнутая антенна.

**Канон (уже в коде, НЕ ломать):** глаза ВСЕГДА красные (`#d0402f` покой /
`#ff6a4a` активность / `#ff9a4a` пик); зелёный — только ИНСТРУМЕНТ (эмиттер
латальщика); «закон одного пигмента» — один акцент-цвет на юнита.

## 2. Три уровня чтения (правило читаемости)

Игрок распознаёт врага за 0.2с в темноте на ходу. Три уровня, каждый работает один:

1. **СИЛУЭТ = ТИП.** Тест «чёрной заливки»: залей юнита одним цветом — тип должен
   угадываться. Карта силуэт-архетипов (держать дистанцию между ними):
   - копатель — компактный ГОРБ с носовым инструментом;
   - собиратель — НИЗКИЙ и ШИРОКИЙ с ёмкостью;
   - рейдер — вертикальный ОСТРЫЙ ромб;
   - охотник — горизонтальный ДРОТИК;
   - взломщик — ПРАВИЛЬНЫЙ многоугольник (неестественная геометрия = «математик»);
   - снайпер — точка с ДЛИННОЙ ЛИНИЕЙ (ствол доминирует);
   - мошкара — точки-мусор (анти-силуэт);
   - залежень — ПОЛУ-ФОРМА, срезанная линией породы;
   - закладка — тело + доминирующая СФЕРА;
   - латальщик — мягкая КАПЛЯ (единственный «добрый» контур);
   - таран — МАССИВНЫЙ клин (самый тяжёлый силуэт);
   - мортира — приземистый КОРОБ с задранной трубой;
   - скверносей — ДЛИННЫЙ низкий сегментник с дорсальным наростом.
   Пары риска (следить при выборе вариантов): копатель↔закладка (сфера-заряд обязана
   доминировать), охотник↔рейдер (горизонталь против вертикали), охотник↔таран
   (масса и «наземность» тарана).
2. **ЧРОМА = СЕМЕЙСТВО (роль).** Акцент — обводка корпуса + тон инструмента:
   - ТРУД (копатель, собиратель) — олива/зелёно-серая (`#5a7a3a`);
   - НАЛЁТ (рейдер, охотник) — красно-оранж (`#c83828`/`#e8642a`);
   - ДАЛЬНИЙ БОЙ/ВЗЛОМ (снайпер, взломщик) — токсичная зелень (`#9aae5a`/`#7ac83a`);
   - ОСАДА (таран, мортира) — лиловая (`#7a3a6a`/`#8a5a9a`);
   - СКВЕРНА (скверносей + маяки) — фиолет (`#9a6aae`, роднит с помехами);
   - САППОРТ (латальщик, закладка как «жертвенный» труд) — изумруд-инструмент /
     охра заряда (`#7a6a30`);
   - мошкара — вне хромы (мусор).
3. **ДЕТАЛЬ = ФУНКЦИЯ.** Один инструмент, увеличенный до гротеска: бур, кузов,
   игла, ствол, заряд, эмиттер. Функция без чтения текста.

## 3. Анимация = телеграф (правило «Clarity»)

Каждый видимый стейт кода получает СВОЮ анимационную фазу. Стейты уже есть:

| Хук в коде | Фаза | Требование |
|---|---|---|
| `e.state2===IDLE` | покой | «дыхание» (1–2px, sin от `e.seed`) + пульс узла жизни |
| `e.state2===MOVING` (`e.progress`) | ход | локомоция ТИПА (семенение/волна/полёт) — фаза от `progress`, не от глобального t (нет скольжения ног) |
| `e.drilling` | работа | инструмент в движении (поршень/ротор/жвалы) |
| `e.cstate==='wind'` (`cT`) | замах | НАКОПЛЕНИЕ: сжатие/оттяжка/разгорание — читается ДО удара |
| `e.cstate==='charge'` (`cvx/cvy`) | рывок | вытяжение по вектору + след |
| `e.cstate==='recover'` | откат | обмякание, инструмент болтается |
| `e.draining`/`e.hacking` (`drainT`) | канал | цикличный «глоток»/тик — прогресс виден |
| `e.firing` | залп | вспышка + ОТДАЧА корпуса |
| `e.aimAng` | прицел | доворот с ИНЕРЦИЕЙ (лерп-лаг), не мгновенный |
| `e.carry` | груз | масса видна: осадка/раскачка/заполнение |
| `e.mpState==='armed'` (`mpT`) | взведён | смена позы + эскалация мигания |
| `e.lurkState` (`buried/wind`) | засада | почти невидим → эскалация |
| `e.stunT` | стан | глаз ГАСНЕТ, дуга-искра статики над корпусом, поза обмякла |
| `e.slowT` | глушение | движения половинной частоты + зелёные капли-помехи |
| `e.knockT` | отброс | крен против вектора, детали болтаются |
| `e.dying` (`deathT`) | смерть | общий «слом» (см. §5) + пер-семейный акцент |

Техтребования: только транс формации и синусы (`rotate/translate/scale`,
`Math.sin(t*f + e.seed)`), НИКАКИХ `ctx.filter`/`shadowBlur` (⚠️ у рейдера сейчас
легаси-`shadowBlur` — снять при реализации), `'lighter'` — только вспышки/каналы.
Бюджет: ≤15 примитивов на врага; мошкара — ≤5 (её МНОГО).

## 4. Двухслойная реализация: процедурка = скелет ассета

Цель: те же дизайны позже получают растровые ассеты БЕЗ переделки анимации.

- Юнит типа рисуется как НАБОР СЛОЁВ с якорями (слоты): `body` (центр, ориентация),
  `tool` (инструмент, свой пивот+угол), `eye`, `node` (узел жизни), опц. `cargo`,
  `aux` (противовес/деталь). Анимация двигает ЯКОРЯ (трансформы), слой рисуется
  в локальном кадре якоря.
- Процедурный рендер каждого слоя — отдельный маленький хелпер; замена на растр =
  `if (PART_SPRITES[key]) drawImage(...) else процедура` В ТОМ ЖЕ трансформе
  (паттерн `render_borer._shieldBody` / `drawToothRing`).
- Ключи ассетов — ГЛОБАЛЬНЫЕ плоские: `enemy:<type>:<layer>`
  (напр. `enemy:digger:body`, `enemy:digger:tool`). Манифест — `enemy_assets.js`
  (клон `module_assets.js`: url/scale/offX/offY/rot, генерится позже).
- Канонический кадр слоя: «вперёд = +X» (как детали юнита) — совместимо с
  `setPartSprite`/пивотами.
- Общие джанк-хелперы (рисуются поверх body ЛЮБОГО типа, детерминированы от
  `e.seed`): `junkPatch(ctx,x,y,w,h,seed)` — заплата с заклёпками;
  `junkWrap(ctx,...)` — витки провода; `junkChip(ctx,...)` — обломанный край;
  `lifeNode(ctx,x,y,r,t,seed)` — узел жизни с пульсом. В растровом варианте эти
  детали уже нарисованы В ассете — хелперы гейтятся `if (!PART_SPRITES[bodyKey])`.

## 5. Общие оверлеи состояний (один код на всех)

- **Смерть** — есть (`drawEnemyDeath`: крен+искры). Добавить пер-семейный акцент
  одной деталью: у труда отлетает инструмент, у осады — панель, у летунов — крыло
  (маленький осколок-примитив по вектору, 0.3с).
- **Стан (`stunT`)** — глаз гаснет до `#5a2a24`, над корпусом дуга-статика
  (ломаная 2–3 сегмента, мерцает), поза-обмякание (rotate 4–6° к «вниз»).
- **Глушение (`slowT`)** — частоты всех осцилляторов ×0.5 + 1–2 зелёные капли.
- **Отброс (`knockT`)** — крен против вектора отброса, свободные детали (тросы,
  канистры, хвосты) отлетают маятником.
- **Дружественный** — лазурный ореол (есть) + глаз НЕ красный, а бирюзовый
  (`#5ad2b4`) — дружелюбие читается на самом юните, не только ореолом.
- **HP-бар** (`mast_hpbar`) — как есть.

## 6. Каталог: 13 типов × 5 вариантов

Формат: **Имя** — силуэт/джанк; *анимация* (стейты кода). Выбирать по одному
(или комбинировать детали). Рекомендация дизайнера — ★.

### 6.1 КОПАТЕЛЬ (digger) — проходчик, ищет города
- A ★ «Крот-башмак» — горбатый корпус-ковш из двух лоскутов, бур-конус на нижней
  «челюсти», сверху заплата+узел жизни; *поршень*: бур долбит вперёд-назад, корпус
  клюёт в такт (`drilling`), на ходу — переваливается (rock ±3°, фаза от `progress`).
- B «Шнек-червь» — голова-бур + 1–2 сегмента-вагонетки цугом (сочленения-гармошки);
  *гусеница*: сегменты сжимаются-растягиваются волной на ходу; при копке голова
  вращает штрих-резьбу (ротор).
- C «Ронин-стрела» — асимметрия: бур на длинной руке-стреле СЛЕВА, справа
  бак-противовес на тросе; *шарнир*: стрела опускается к породе и дрожит при копке,
  бак-маятник болтается на ходу (лаг за движением).
- D «Жвала» — плоский клоп, спереди два полубура-жвала; *ножницы*: жвалы сходятся/
  расходятся в такт копке, семенящие ножки на ходу.
- E «Фреза-деградант» — косое зубчатое мини-колесо сбоку корпуса (жуткая рифма с
  «Канониром» игрока — «они тоже когда-то печатали»); *ротор*: фреза крутится при
  копке, в покое юнит качается неваляшкой. ⚠️ риск спутать с юнитом — сильно меньше,
  грязнее, глаз красный.

### 6.2 СОБИРАТЕЛЬ (collector) — носильщик добычи
- A «Рикша» — кузов-тачка ВПЕРЕДИ на оглоблях, толкает перед собой; *подпрыгивание*:
  кузов трясётся на ходу, добыча (`carry`) подскакивает; на подборе — клешни
  закидывают ресурс дугой.
- B «Верблюд» — две корзины по бокам, одна больше (асимметрия); *коромысло*:
  корзины качаются противофазой на ходу; гружёный — крен на сторону полной.
- C «Кран-крюк» — добыча висит ПОД брюхом на тросе с крюком; *маятник*: груз
  отстаёт от движения (физичный лаг), на подборе трос-лебёдка наматывается
  (2–3 витка анимацией).
- D «Пылесос» — хобот-гофра спереди + бак-цистерна сзади; *змейка*: хобот шарит
  по земле синус-волной, подбор = «глоток» (пульс бака, `carry` появляется в баке).
- E ★ «Паланкин-трудяга» — плоская спина-поддон, добыча пристёгнута ремнём;
  *осадка под весом*: пустой семенит бодро (высокая частота ножек), гружёный —
  оседает на 2px и идёт медленно-тяжело (амплитуда/частота ножек падают). Груз
  ЧИТАЕТСЯ по походке — телеграф «догони и отбери».

### 6.3 РЕЙДЕР (raider) — вор энергии базы
- A ★ «Шприц» — вертикальный клин-игла, в брюхе прозрачная КОЛБА; *заполнение*:
  при дренаже (`draining`, `drainT`) колба наливается голубым снизу вверх с
  плеском (уровень = drainT — прогресс-бар В ТЕЛЕ врага!), унос — жидкость
  плещется на манёврах (наклон уровня по скорости).
- B «Клещ» — раздутое брюшко-бак сзади; *набухание*: брюшко растёт (`scale` ∝
  drainT), присосался = мелкая дрожь всего тела; убит с грузом — брюшко «лопается»
  голубой вспышкой (возврат энергии — уже есть механика?← нет: просто FX).
- C «Канистра-курьер» — узкое тело + 2 разномастные канистры по бокам (одна мятая);
  *вибрация*: канистры дребезжат в полёте (1px, разные фазы), при дренаже — шланг
  дугой к ядру базы (кривая Безье, бегущие точки).
- D «Медуза» — колокол + свисающие щупы-провода; *пульс медузы*: колокол сжимается/
  расширяется в полёте (движение = толчки), при дренаже щупы втыкаются вниз и
  по ним бегут голубые точки вверх.
- E «Сорока» — вилка-хвост, клюв-крюк; *стрекотание*: хвост-вилка быстро подрагивает
  в полёте; украв — прижимает светящийся заряд лапками к груди (заряд-шар
  из-под корпуса, поза «жадности»).

### 6.4 ОХОТНИК (hunter) — таран юнита
- A ★ «Гарпун-тетива» — тонкое древко с тяжёлой носовой массой; *оттяжка*: на
  `wind` весь корпус ОТТЯГИВАЕТСЯ назад против вектора цели (3–4px, как тетива)
  + нос разгорается; `charge` — струной вперёд (вытяжение есть), `recover` —
  болтается расслабленно (маятник затухания).
- B «Сокол-серп» — серповидные крылья; *складывание*: патруль — редкие мощные
  взмахи (1 Гц), `wind` — крылья поднимаются, `charge` — ПРИЖАТЫ (пике сокола),
  `recover` — растопырены тормозом.
- C «Ракета-кустарь» — сварной цилиндр, стабилизаторы вкривь, коптящее сопло;
  *факел*: постоянный мигающий выхлоп, на `wind` факел разгорается втрое
  (телеграф светом), полёт с лёгким рысканием (wobble угла).
- D «Копейщик» — корпус + копьё на пантографе-ножницах; *взвод механизма*:
  пантограф складывается на `wind` (копьё к телу), на `charge` ВЫСТРЕЛИВАЕТ
  копьё вперёд, корпус догоняет; после — копьё вываливается вниз на шарнире.
- E «Капкан-створка» — раскрывающиеся челюсти спереди; *раскрытие*: `wind` —
  челюсти медленно распахиваются (угол ∝ cT — аналоговый телеграф), удар —
  схлопываются; промах (`cBlocked`) — грызут воздух дважды.

### 6.5 ВЗЛОМЩИК (hacker) — пилит файрволл базы
- A «Клещ-печатник» — плоский краб с иглами по периметру; *механограф*: при
  взломе иглы бьют по очереди (как печатная машинка), корпус доворачивается
  ступеньками-тиками (дискретный поворот раз в 0.4с — «перебор кода»).
- B ★ «Хор антенн» — тренога + 4–5 антенн РАЗНОЙ длины с шариками; *настройка*:
  в покое антенны дрожат каждая своей частотой (хаос), при взломе постепенно
  СИНХРОНИЗИРУЮТСЯ (частоты сходятся к одной по мере прогресса файрволла) —
  игрок видит стадию взлома по степени унисона. Жутко и читаемо.
- C «Кассетник» — коробок с двумя бобинами; *перемотка*: бобины крутятся с
  рывками при взломе (стоп-старт), из корпуса тянется провод-шлейф к базе,
  по нему бегут зелёные биты.
- D «Штекер-осьминожек» — тело-разъём + 3 щупа с вилками; *втыкание*: щупы по
  одному втыкаются в «порты» (невидимые точки у базы), каждое втыкание толкает
  корпус отдачей; выдернутый щуп искрит.
- E «Диафрагма» — один огромный глаз-линза в кольце сегментов; *щелчки зрачка*:
  диафрагма резко сужается/расширяется в такт «подбору», сегменты кольца
  загораются по кругу (лоадер = прогресс сегмента файрволла).

### 6.6 СНАЙПЕР (sniper) — дальний обстрел юнита
- A «Рельса-жердь» — крошечное тело + непропорциональный ствол×2.5 тела;
  *инерция прицела*: ствол ведёт за `aimAng` с лагом-пружиной, выстрел =
  ОТКАТ всего тела назад по оси ствола (3–4px) + качание ствола.
- B «Складная тренога» — в полёте ствол сложен вдоль тела; *раскладка*: занял
  позицию (стоит, юнит в радиусе) — ствол раскладывается + выносные упоры
  в стороны (телеграф «сейчас начнёт бить»), кайт — мгновенно складывается.
- C ★ «Кальмар-хобот» — ствол = вытяжной хоботок; *накачка*: перед выстрелом
  (`SNIPER_COOLDOWN` виден по `e.fireCd`?—есть ли поле: если нет, взять фазу от
  последнего `firing`) светящаяся точка ползёт от тела к дулу (заряд-телеграф,
  игрок успевает спрятаться), выстрел — хоботок хлестает отдачей (волна по стволу).
- D «Луч-нитка» — фонарь-корпус; *прицельная нить*: тонкая тлеющая линия к юниту
  (алая, α~0.15, дрожит), за 0.3с до выстрела замирает и вспыхивает. Сильнейший
  геймплей-телеграф; ⚠️ дешевле всех, но меняет ощущение сложности — обсудить.
- E «Горб конденсаторов» — ствол снизу корпуса, сверху гребень из 4 банок;
  *зарядная лесенка*: банки загораются по одной (готовность), залп — все гаснут
  + клапан-пшик (3 линии пара).

### 6.7 МОШКАРА (swarm_midge) — рой-мелочь (дёшево! их много)
- A ★ «Искра-клоп» — текущий силуэт + редкий twitch-скачок на 1–2px по seed
  (нервный гнус); *дрожь крыльев* 30 Гц (есть).
- B «Пепел-мотылёк» — треугольная чешуйка; *переворот*: вращается вокруг своей
  оси — мерцает то широкой, то узкой стороной (1 rotate, дёшево).
- C «Глаз-семечко» — ТОЛЬКО красная точка + волосок-хвост; *виляние хвоста*.
  Минимальная цена — вариант для больших роёв.
- D «Гнус-цепочка» — визуальная нить между 2–3 ближними мошками (1 line);
  *колыхание нити*. Рой читается как организм; чуть дороже (поиск соседа —
  кэшировать пару при спавне).
- E «Стробо-блоха» — движение микро-телепортами с фантомом на 1 кадр (прошлая
  позиция, α=0.3); *глитч-гнус* — деградация в чистом виде.

### 6.8 ЗАЛЕЖЕНЬ (lurker) — засада в породе
- A «Люк-обманка» — диск-«камень», в `wind` приподнимается щёлочкой (из-под неё
  красный глаз), *крышка*: при выпаде крышка отлетает на петле и болтается.
- B «Челюсть-капкан» — две зазубренные дуги торчат из породы (как камни);
  *смыкание*: в засаде дышат на 1px, `wind` — размыкаются, `charge` —
  схлопываются на цели; после — пережёвывание (2 микро-смыка).
- C ★ «Перископ» — в засаде виден ТОЛЬКО глаз на тонком штоке, ПОВОРАЧИВАЕТСЯ
  за юнитом (`atan2` на юнита — жуть слежки); `wind` — шток вытягивается выше,
  `charge` — тело вырывается из-под земли (частицы породы — `dust.burst` есть).
- D «Джек-пружина» — гармошка-цилиндр; *обратный squash*: `wind` — сжимается НИЖЕ
  уровня земли (исчезает — обманка!), `charge` — распрямляется пружиной с
  перелётом (overshoot 20%).
- E «Кит под песком» — горб медленно «плывёт» волной ±0.3 тайла (визуально;
  логика сидит на месте — рисуем офсет синусом), над горбом дрожит крошка
  породы; выпад — из гребня волны.

### 6.9 ЗАКЛАДКА (mine_planter) — смертник к базе
- A ★ «Носильщик бомбы» — заряд-бочка НА СПИНЕ на ремнях, бочка БОЛЬШЕ тела
  (силуэт-доминанта против путаницы с копателем); *перекат*: бочка перекатывается
  в ремнях на ходу (rotate по progress), `armed` — юнит садится и ОБНИМАЕТ бочку
  (поза жертвы), мигание эскалирует (`mpT`).
- B «Прицеп-камикадзе» — заряд на тележке сзади; *вихляние*: тележка-маятник
  отстаёт на поворотах, `armed` — отцепляет тележку и накрывает её собой.
- C «Крот-сеятель» — заряд в брюхе, виден сквозь щель-люк; *ввинчивание*: при
  закапывании крутится на месте (rotate), `armed` — снаружи ТОЛЬКО качающийся
  усик-антенна (почти невидим — страшнее).
- D «Двухфазник» — заряд = отделяемая голова; `armed` — тело отсоединяет голову-
  мину и отползает глохнуть в сторону (два объекта: обманка). ⚠️ требует лоджик-
  правки в ai (декой-сущность) — дороже.
- E «Будильник» — заряд-клубок проводов с циферблатом; *стрелка*: крутится тем
  быстрее, чем ближе юнит (аналоговый телеграф вместо мигания), взрыв на «12».

### 6.10 ЛАТАЛЬЩИК (mender) — хилер волн
- A «Пчела-медик» — полосатое брюшко, жало-инжектор вниз; *укол*: лечение —
  садится НА пациента, жалит (движение вниз), по трубке бежит зелёный пульс.
- B «Сварщик» — маска-щиток + горелка-манипулятор; *сварка*: у пациента сыплются
  зелёно-жёлтые искры точечной сварки (3–4 линии), щиток опущен; в полёте
  щиток поднят (виден глаз).
- C ★ «Штопальщик» — катушка провода под брюхом + игла-манипулятор; *стежки*:
  лечение = игла делает стежки над раной пациента (зигзаг-штрихи проявляются
  и тают), катушка вращается, к пациенту — нить. «Чинит = шьёт» — идеально
  для лора донашивания.
- D «Кадильщик» — курильница на цепочке под брюхом; *качание*: курильница-маятник,
  над пациентом — зелёный дымок частиц (лечение «обрядом» — культ деградантов).
- E «Дефибриллятор» — два манипулятора с клеммами; *разряд*: прикладывает клеммы,
  вспышка, пациент вздрагивает (микро-knock визуально — 1px крен). Комично-жутко.

### 6.11 ТАРАН (siege_ram) — ломает структуры игрока
- A «Наковальня» — ржавая плита-морда с зубами сколов; *копыта*: в `wind` роет
  опорами землю (крошка частиц), `charge` — плита звенит вибро-дрожью 1px,
  удар — глубокий клевок корпуса.
- B ★ «Поршень-молот» — молот на направляющих ВНУТРИ рамы (виден в прорези);
  *взвод*: `wind` — молот отходит назад по прорези (аналоговый телеграф =
  видно КАК заряжается), `charge` — молот выстреливает вперёд раньше корпуса,
  удар передаёт волну по раме (1–2px рябь).
- C «Бульдозер» — отвал из сваренных кусков (лоскутный щит); *скрежет*: перед
  рывком отвал опускается и скребёт землю (искры + борозда-штрих), в рывке
  куски отвала дребезжат каждый своей фазой.
- D «Маятник-гиря» — шар-гиря на цепях под А-рамой; *раскачка*: `wind` — гиря
  раскачивается всё шире (амплитуда ∝ cT), `charge` — корпус летит, гиря
  вперёд на цепях, после удара гиря мотается затухая.
- E «Носорог со сменным рогом» — гигантский рог-балка слева + 2 запасных
  обрубка справа (асимметрия-склад); *износ*: после каждого удара на роге
  появляется трещина-декаль, после 3-го рог ОТВАЛИВАЕТСЯ и пантограф ставит
  запасной (чистый джанк-сторителлинг). ⚠️ нужен счётчик ударов на `e` — дёшево.

### 6.12 МОРТИРА (siege_mortar) — навесной обстрел структур
- A ★ «Жаба-плевок» — короб с коротким жерлом + ЗОБ-мешок под жерлом; *раздув*:
  зоб надувается к выстрелу (телеграф издали — игрок успевает среагировать),
  залп — зоб резко сдувается, корпус приседает отдачей.
- B «Котёл» — пузатый котёл-ствол с крышкой на цепочке; *крышка*: на заряде
  крышка откидывается и нутро разгорается (свет из жерла), залп — котёл
  подпрыгивает, крышка хлопает.
- C «Требушет-кустарь» — рычаг с корзиной-противовесом из хлама; *взвод рычага*:
  медленно опускается (аналоговый прогресс), швыряет — рычаг машет, хлам в
  корзине подпрыгивает.
- D «Оргáн» — три разнокалиберные трубы веером (все — чужие, разные); *очередь*:
  стреляет из труб по очереди (вспышка у разных дул), отдача перекашивает
  короб в сторону стрелявшей трубы.
- E «Паровик» — труба-дымоход, заклёпанный бак; *пар*: постоянный дымок из
  дымохода (2–3 тающих круга), перед залпом пар бьёт из всех щелей + вибро-
  «свисток» (штрих-линии у клапана), залп.

### 6.13 СКВЕРНОСЕЙ (blight_sower) — сеет маяки помех
- A «Сеятель с мешком» — мешок-спорник на спине, рука-манипулятор; *посев-жест*:
  зачерпывает из мешка и ВТЫКАЕТ маяк в землю (читаемый жест посадки), мешок
  худеет с каждым маяком.
- B «Слизень» — без ножек, сегменты волной; *перистальтика*: тело идёт волной
  сжатий, за ним короткий гаснущий лиловый след; маяк «выдавливается» из
  хвостового сфинктера (мерзко = правильно).
- C «Кадильщик скверны» — штанга с качающейся курильницей; *капля*: курильница-
  маятник, на нижней точке отрывается «капля»-маяк и ввинчивается в землю.
- D «Инъектор» — бак с лиловой жижей + бур-шприц под брюхом; *впрыск*: сверлит
  лунку (ротор), впрыскивает (уровень в баке падает скачком), маяк прорастает
  из лунки.
- E ★ «Матка с выводком» — маяки-«детёныши» сидят на спине РЯДКОМ (видно,
  сколько осталось — считаемый боезапас!); *спрыгивание*: детёныш сам спрыгивает,
  семенит на 1 тайл и ввинчивается; матка вздрагивает при каждом отделении.
  ⚠️ спрыгнувший = короткая FX-сущность (0.5с анимации до превращения в маяк).

## 6-v2. Каталог, проход 2 — «кибер-механика» (вероятность = рекомендация выбора, сумма 100%/юнит)

Проход с упором на МАШИННУЮ кинематику. Общие механические принципы v2 (словарь движений,
дополняет §3; все — трансформы/синусы, без фильтров):
- **Серво-тик**: повороты СТУПЕНЬКАМИ с микро-овершутом и доводкой (шаговый мотор), не плавный лерп.
- **Гидравлика**: видимый шток-поршень; медленный взвод под давлением → быстрый рабочий ход → пневмо-пшик (2–3 линии пара).
- **Трос и блок**: конечность тянется тросом; под нагрузкой трос прямой, без — провисает (2-точечная кривая).
- **Маховик/ротор**: запас энергии ВИДЕН вращением (спицы сливаются на раскрутке); сцепление врубается — рывок.
- **Кулер-индикатор**: вентилятор на корпусе, обороты = нагрузка (заряд/бег/канал) — бесплатный телеграф состояния.
- **Теплоотвод**: рёбра радиатора разгораются оранжевым при перегрузке, остывают градиентом после.
- **Кабели-вены**: наружные жгуты; при работе органа по жгуту бегут световые сгустки.
- **Глитч-экран**: экранчик-морда с символами, битые пиксели/сдвиги строк (деградация).
- **Стробо-неон**: грязная неон-полоска, мигает с пропусками (сломанный балласт).
- **Механическая подача**: барабаны, ленты-транспортёры, досылатели, защёлки, выбрасываемые гильзы — процесс работы виден как механизм.

Формат: **Имя (P%)** — вид; *движение/анимация*. Стейт-хуки — те же (§3).

**КОПАТЕЛЬ:** A «Шагоход-экскаватор» (30) — кабина на 4 гидролапах-башмаках, бур на стреле с видимым поршнем; *шаг с фиксацией* (перенос → ЩЁЛК → корпус подтягивается), копка — поршень качает бур, кулер раскручивается · B «Кардан-крот» (25) — открытый карданный вал + шестерня редуктора к буру; *гусеничные скобы* бегут по бокам, твёрдая порода = пробуксовка рывками с искрой · C «Пневмо-дятел» (20) — зубило с ударником + баллон сверху; *прыжковые шажки с пшиком*, копка = очередь ударов 3–4 Гц, баллон дрожит · D «Многорук-старатель» (15) — 3 разнокалиберные руки (кирка/бур/скребок), смена поворотом плечевого барабана; копка-комбо · E «Червь-ТБМ» (10) — сегменты с внутренним светом; *перистальтика с анкер-распоркой* задних колец, головной обтюратор раскрывается лепестками.

**СОБИРАТЕЛЬ:** A «Вилочный кар» (25) — вилы спереди, противовес ВЫДВИГАЕТСЯ при подъёме груза; *ролики + танковый разворот на месте* · B «Магнит-кран» (25) — стрела с электромагнитом на тросе; подбор = опустить → ЩЁЛК-прилипание с искрой → лебёдка; груз-маятник в пути · C «Центрифуга» (15) — кузов-барабан медленно вращается, груз перекатывается внутри (виден в прорезях) · D «Тягач с прицепом» (20) — крошечный тягач + платформа на сцепке; прицеп вихляет, на стопе накатывается со стуком · E «Рюкзак-гидравлик» (15) — клетка-рюкзак + 2 гидро-руки грузят ЧЕРЕЗ ПЛЕЧО; перегруз — колени-поршни проседают.

**РЕЙДЕР:** A «Инкассатор-штекер» (30) — выдвижной порт-хобот, 3 лепестка разъёма раскрываются перед стыковкой; дренаж = кольца света бегут по гофре; полёт на 2 роторах с креном · B «Катушка Теслы» (20) — дренаж БЕЗ контакта: дуга-молния (дрожащий зигзаг) к ядру, катушка раскаляется · C «Веретено конденсаторов» (20) — 3 кольца раскручиваются в разные стороны, светятся по мере заполнения; унос — тормозят рывками · D «Пиявка-клапан» (15) — присоска с видимой диафрагмой, качает энергию глотками, бак булькает светом · E «Врезка в магистраль» (15) — тянет ВРЕМЕННЫЙ кабель к базе (нить, гаснет за 2с), отход — кабель рвётся искрой.

**ОХОТНИК:** A «Вектор-перехватчик» (30) — 2 поворотных сопла на пилонах; *телеграф = ДОВОРОТ сопел на цель* + форсаж-кольца, рывок — вибро перегрузки, после — раскалённый нос остывает · B «Гиро-клинок» (20) — внешний ротор-лезвие, обороты = агрессия; рывок диском ребром · C «Пружинный арбалет» (20) — нос-болт на направляющей, защёлка ОТТЯГИВАЕТ его назад (видна пружина), выстрел собой · D «Звено-сцепка» (15) — 3 модуля на магнитах летят звеном, на рывок СМЫКАЮТСЯ в копьё, на recover рассыпаются · E «Мотор-циклоп» (15) — один огромный турбовентилятор = морда, глаз в ступице; замах = РЕВЕРС лопастей (стоп-кадр → обратное вращение).

**ВЗЛОМЩИК:** A «Барабан отмычек» (30) — револьверный барабан с 6 пробниками; тик-поворот → пробник выдвинулся-попробовал-искра → следующий; остаток ключей = прогресс · B «Рельсовый сканер» (20) — портальная рамка, каретка ездит по рельсе (принтер), захват строки = фиксация + смена лампы · C «Паук-клавиатурщик» (20) — 6 тонких ног ПЕЧАТАЮТ по стене базы бегущей волной, экран-морда сыплет символы · D «Индукционная петля» (15) — обруч к стене, внутри крутится луч-развёртка, найден порт — стоп и вспышка · E «Кассета-червь» (15) — выпускает ленту-шлейф в щель, лента затягивается рывками, корпус упирается лапами.

**СНАЙПЕР:** A «Рельсотрон-кустарь» (30) — ствол из 2 шин, 4 катушки ВДОЛЬ загораются последовательно к дулу (бегущий телеграф), выстрел — шины расходятся отдачей · B «Пневмо-упоры» (20) — перед выстрелом лапы-упоры В РАСПОР в стены (фиксация), выстрел, сложился — кайт · C «Оптика-башня» (20) — линза с диафрагмой + мигающий лазер-дальномер; наводка = телескоп-фокусировка · D «Гильзомёт» (15) — затвор-рычаг передёргивается после выстрела, гильза-светляк вылетает и гаснет · E «Кардан-стабилизатор» (15) — корпус в рамке-карданах: рамка качается от манёвров, СТВОЛ ОСТАЁТСЯ НАВЕДЁННЫМ (контр-вращение).

**МОШКАРА:** A «Нанострой» (30) — мгновенные перестроения звеньями 3–5 (снап в линию/клин на 0.5с → рассып) · B «Синапс» (25) — микро-разряд между ближними (1-кадровая линия) — рой «думает» · C «Ролик-блоха» (15) — катится по стенам, срывается в прыжок · D «Сбойный пиксель» (15) — фриз 0.3с с миганием → рывок-догон · E «Обойма» (15) — вылетают из гнезда сцепленной кассетой, рассыпаются веером у цели.

**ЗАЛЕЖЕНЬ:** A «Гидро-челюсть» (30) — фальш-плита на 4 УГЛОВЫХ ПОРШНЯХ (штоки видны при подъёме = мех-телеграф), рычаг-челюсть распрямляется одним ударом · B «Гарпунщик» (20) — тело в породе, ВЫСТРЕЛИВАЕТ голову на тросе (язык хамелеона), лебёдка втягивает · C «Пресс с потолка» (20) — плита на направляющих штангах СВЕРХУ прохода, взвод = подтяжка на цепях клац-клац · D «Сегментный удав» (15) — тело выходит волной сразу в 2–3 местах (между — под землёй): читается «оно большое» · E «Ложный лут» (15) — мимикрия под контейнер с глитч-пикселями, при подходе раскрывается веером панелей.

**ЗАКЛАДКА:** A «Сапёр-манипулятор» (30) — тележка + рука несёт мину на демпфере; установка: опустил → ВЫДЕРНУЛ ЧЕКУ (колечко отлетает) → глохнет рядом · B «Мина-наездник» (25) — мина-колобок сама спрыгивает и ввинчивается, носильщик пятится прикрывая · C «Ленточный укладчик» (15) — мина съезжает по транспортёру, лапа-плита утрамбовывает · D «Механизм наружу» (15) — открытые шестерни + анкер тик-так; ближе юнит — анкер быстрее (аналоговый детектор) · E «Кокон на растяжке» (15) — подвешивает мину к ПОТОЛКУ на тросе. ⚠️ меняет геймплей (потолочные мины) — правка логики.

**ЛАТАЛЬЩИК:** A «Барабан инструментов» (30) — турель-барабан (сварка/клей/степлер) щёлкает под задачу; степлер оставляет скобы-блёстки на пациенте · B «Капельница» (25) — шланг в пациента, по шлангу сгустки; СВОЙ узел жизни тускнеет при отдаче (жертвует собой — лор!) · C «Принтер-заплатка» (20) — рамка над раной, каретка «печатает» заплату строчками · D «Рой-ремонтник» (15) — выпускает 3–4 зелёных микро-ботов, ползают по пациенту, возвращаются в соты · E «Молитвенный сервомех» (10) — ритуал-поклоны манипуляторов перед лечением (культ-глитч).

## 7. План разработки (для реализующей сессии)

**Фаза 0 — выбор.** Владелец выбирает вариант на каждый тип (или миксует детали).
Дефолт-пресет дизайнера: ★-варианты (A/E/A/A/B/C/A/C/A/C/B/A/E).

**Фаза 1 — каркас (без смены дизайнов).**
1. В `render_enemy.js`: реестр-диспетчер `EDRAW[type]` вместо if-цепочки;
   общий пролог (cx/cy/r, t, seed-фазы) и общий эпилог.
2. Хелперы джанка: `junkPatch/junkWrap/junkChip/lifeNode` (детерминизм от seed).
3. Общие оверлеи состояний (§5): stun/slow/knock/friendly-глаз; вынести
   существующие телеграф-кольца (`wind`) в общий хелпер.
4. Ассет-хук: `_ePart(ctx, key, drawProc)` — `PART_SPRITES[key]` → drawImage,
   иначе процедура (паттерн `_shieldBody`); ключи `enemy:<type>:<layer>`.
5. Снять легаси-`shadowBlur` у рейдера. Файл render_enemy.js при разрастании
   бить по семействам: `render_enemy.js` (диспетчер+общее+труд/налёт) +
   `render_enemy2.js` (осада/спец) — или по согласованию.
   ⚠️ Загрузчик index.html + строка в CLAUDE.md при добавлении файла.

**Фаза 2 — дизайны по семействам** (батч = код → сандбокс-проверка → тюнинг):
1. ТРУД: копатель, собиратель (+ мошкара — дёшево, рядом).
2. НАЛЁТ: рейдер, охотник.
3. ДАЛЬНИЙ/ВЗЛОМ: снайпер, взломщик.
4. ОСАДА: таран, мортира.
5. СПЕЦ: залежень, закладка, латальщик, скверносей.
Проверка каждого батча в ПЕСОЧНИЦЕ (T в меню, панель спавна врагов справа —
все 13 типов, спам без лимитов): скрины idle/ход/работа/замах/смерть; стан —
ЭМИ-реликтом или `e.stunT=2` евалом; слоу — `e.slowT=2`.

**Фаза 3 — перф-гейт.** Спавн 30 мошкары + 10 смешанных: замер кадра
(в песочнице перф-спам разрешён). Бюджет: суммарно ≤1.5мс на всю пачку на
целевой машине (см. память о THERMAL). Срезы: LOD мошкары, кэш градиентов, нет
per-frame аллокаций в циклах отрисовки.

**Фаза 4 — растровый слой (позже, по готовности ассетов).**
1. `enemy_assets.js` — манифест (клон `module_assets.js`), в загрузчик.
2. Канонические кадры слоёв (вперёд=+X), экспорт-инструкция для художника:
   размер слоя ≈ 2r×2r (r=(TILE−12)/2=18px → ассеты 64–96px с запасом),
   пивот в центре якоря слоя.
3. Подмена через `_ePart` уже готова с Фазы 1 — только положить ассеты.
4. (Опционально) секция «Враги» в tools/rig_editor.html для калибровки
   scale/off/rot ассетов — по паттерну SPRUT_PARTS-карточек.

**Фаза 5 — полировка.** Пер-семейный осколок в `drawEnemyDeath`; бирюзовый глаз
дружественных; сверка силуэт-теста (скрин со всеми 13 залитыми тёмным — попарная
различимость); обновить `spec_enemies.md` (раздел рендера) и строку
`render_enemy.js` в CLAUDE.md.
