# spec_world.md — Мир: генерация, слои, объекты

> Реализованная спецификация мира. Код: `world.js`, `constants.js` (геометрия),
> `falling.js`/`render_falling.js`, `render_backdrop.js`, палитра — `render_world._STRATA`.

## Нарратив-ось тороида

Мир — тороид. **ВВЕРХ** — погребённая людская цивилизация (постапокалипсис, тёплые тона),
**ВНИЗ** — «внешняя сторона»/космос, хаос (холодные тона к фиолету). Город игрока — нейтральная
земля между ними. Путь наверх = директива «зерно истины».

## Геометрия (constants.js)

- Карта **144×264** (`MAP_W`×`MAP_H`), тор по X: `wrapX`/`wrapPx`/`wrapDeltaPx`, боковых границ нет (только дно BORDER).
- `SURFACE_ROWS=3` — тонкое «небо» сверху.
- Город ГЛУБОКО: `CAVE_X0..X1=22..37`, `CAVE_Y0..Y1=98..105`, `CAVE_FLOOR_Y=105` → над городом ~95 тайлов страт (длинный подъём).
- `PRINTER={x:27,y:104,w:3,h:2}`, `SPAWN_X/Y=30/105`.
- Корка под городом: `CRUST_Y0..Y1=109..110`, `CRUST_HARD=3.2`.
- **4 страты НАД городом** (`CEIL_BANDS=[24,50,78]`, читают `world.hardnessForY`/`layerName`):
  `пепел` (≤24, h 1.6) → `ржавчина` (≤50, h 1.3) → `завал` (≤78, h 1.5) → `перегной` (до города, h 1.0).
- **5 «завалов»-барьеров** (`CEILING_CRUSTS`, y=12/30/50/70/88, hard 3.0→1.7, плотнее к поверхности) —
  спрессованные катастрофами руины; поверхность не сразу достижима; `layerName` → `завал`.
- Под городом: `верхний` (≤0.5·H, h 1.5) / `средний` (≤0.78·H, h 2.5) / `глубокий` (h 4.0).
- Пустоты: `VOID_SCALE`/`VOID_THRESHOLD`, **только ниже города** (`y > CAVE_FLOOR_Y`) — над городом
  коридоров-шорткатов сквозь завалы нет.

## Палитра глубины (render_world._STRATA)

Непрерывный градиент всей колонки, стопы привязаны к tileY: пепел (тёплый серо-песочный, y≈4) →
ржавчина (оранжевый, 24) → завал (охра, 50) → перегной (тёмно-оливковый, 78) → город (нейтральная
земля, 102) → средний (остывающий серый, 160) → глубокий (сине-серый, 215) → бездна (фиолетовый
«космос», 262). `_strat(y)` лерпит `backColor`/`gapColor`/`shadeColor` (мемоизация по int y) —
непрерывность убирает горизонтальный шов на сетке (прежние `layerFloat`/`_LBAND` удалены).

## Генерация (world.js)

- `World(seed)`: `rand` (mulberry32) — размещение пещер; `hash`(seed) + `pnoise` (периодический
  value-noise, бесшовный по кольцу) — плотность зонами (`tile.dens`→`hardness`).
- Туман войны: `seen`/`reveal(cx,cy,r)`; `isSeen` wrap по X.
- Неразрушимый фундамент (`INDESTRUCT`, `layFoundation`) ТОЛЬКО под городом (принтер+спавн) и под
  маркерами чужих городов; остальной пол пещер копается.
- **Чужие города** (дружественные): `genCaverns` → `this.caverns`, бэнды ~0.45–0.87·H, эллипсы,
  `name`/`rep` — задел под задания.
- **Дикие гнёзда**: `genWilds` → `this.wilds`, бэнды ~0.48–0.88·H, `hp` (=`WILD_HP`) для будущего
  рейда, копят `loot` (собиратели) и `charge` (рейдеры). Источники волн.
- Размещение — `placeNest`: бэнды глубины ∝ MAP_H, разнос по тору 2D (`CITY_MIN_GAP_X`).
- `resourceFor(x,y)`: шанс/состав жил растёт с глубиной от пола города (кристалл — к глубине).
- `setAir(x,y)`: ставит `tile.dug=true` (прорытый ход ≠ природная пустота — враги избегают своих
  ходов); `tile.server` → `server.dug=true` (сервер стал «хламом», включает сканер); клетку СВЕРХУ
  кладёт в `unstableTriggers`, если она `unstable`/`boulder` (потеря опоры → срыв).

## Старые серверы (источники данных)

`genServers` → `this.servers` = `SERVER_COUNT`(=10) объектов `{tx,ty,dug,data,done}` В ПОРОДЕ
(бэнды ~0.45–0.86·H; не в пещерах/крусте/у старта; разнос по тору). В `generate` тайл сервера —
ROCK чуть твёрже фона + обратная ссылка `tile.server`. Скан: радиус `SCAN_RADIUS`=2.5 тайла,
полная выкачка `SCAN_TIME`=4с (уход — пауза, прогресс сохраняется) — логика `game.updateServers`,
рендер маркера/хлама/лучей — `render_scan.js`, данные → кодекс (см. `spec_codex.md`).

## Радиация (помехи, НЕ урон)

`poleRad(y)` 0..1 — фон у «полюсов»: растёт к поверхности (`y<RAD_TOP_Y`) и ко дну (`y>RAD_BOT_Y`),
середина тихая. `genRadSources` — `RAD_SOURCES`(=4) локальных очага у базы (разброс по X
`RAD_SOURCE_SPREAD` от спавна, глубина `RAD_SOURCE_BAND=[120,220]`). `radAt(x,y)` = max(полюса,
очаги: в центре 1 → 0 на радиусе `RAD_SOURCE_R`=20) — «гейгер». Очаги невидимы (в дебаге ☢-маркер).
`game.radLevel` плавно тянется к `radAt(юнит)`; эффект — пост-помехи `render_glitch.js`.
- **Детектор загрязнения** — **СВОЙСТВО СКАНЕРА** (НЕ отдельный модуль), открывается узлом меты `mast_sr`;
  гейт `game._contamActive()` = `metaHas('mast_sr') && unit.stats.scanR>0`. Код `radar.js`/`render_radar.js`.
  HUD-виджет «**Гейгер-ветер**» в кибер-ацтек стиле. Когда юнит ВНУТРИ радиуса очага (`d<s.r`),
  `RadarCompass.update` берёт сильнейший очаг, пеленг — `atan2` по тору (`MAP_W`). Визуал: линза-СОНЦЕ —
  лучи-КОРОНА вокруг «разгораются» с интенсивностью загрязнения (длина+яркость+цвет; БЕЗ явного бара),
  морось влетает СО СТОРОНЫ очага (веер `dir±spread`) в ядро-глиф (ромб, вспышка `flash` на попадании),
  ВНУТРЕННЯЯ дуга-пеленг (радиус `R−4`, отступ от обода → виден ход) — сторона. НАМЕРЕННО неточно/«живо»:
  пеленг рыщет (две синусоиды, `RADAR_JIT_*`), приход ВЕЕРОМ, широким при слабом сигнале и узким у очага
  (`RADAR_SPREAD·(1−signal)`). Частицы — нормализ. коорд. (линза радиуса 1), спавн ∝ сигналу (`RADAR_SPAWN`).
  Вне очагов — «снежная» рябь + «СКАН ФОНА». БЕЗ апгрейдов/градаций (интенсивность/точность сами растут
  у очага: ярче корона, крупнее ядро, плотнее морось). UI — `spec_ui.md`.

## Нестабильная порода и валуны

- **Нестабильная** (`tile.unstable`): `genUnstable` метит ROCK ниже города МЕЛКИМИ группами 1–3
  тайла (зерно `hash<UNSTABLE_SEED_CHANCE`, анти-слипание по левому соседу → ~20% покрытия; не
  круста/сервер; только где снизу опора на старте). Визуально — порода + ветвящиеся трещины
  (`render_falling.drawUnstableCracks`; при `shaking` дрожит + тлеет).
- **Валун** (`tile.boulder`): одиночные тайлы, реже (`BOULDER_SEED_CHANCE`), твёрдость
  ×`BOULDER_HARD`=1.9 («самая плотная порода слоя»), большой камень на тайл (`_bigRock`).
- **Срыв** (`falling.FallingRocks.update`): `unstableTriggers` → фаза «дрожит» (`tile.shaking`,
  телеграф) → через `UNSTABLE_FALL_DELAY`≈0.75с срыв (если опоры так и нет): `world.setAir`
  (цепочка вверх) + спавн летящего блока `{tx,py,vy,hardness,resource,boulder}`.
- **Полёт/удар**: гравитация `UNSTABLE_GRAVITY`/`UNSTABLE_MAX_FALL`; бьёт юнита (раз за валун,
  урон случайный в `UNSTABLE_DAMAGE_MIN..MAX`, у валуна `BOULDER_DAMAGE_MIN..MAX` больше).
  Хитбокс — `ROCKFALL_HIT_W`(±0.55 тайла по X) × `ROCKFALL_HIT_H`(±0.3 по Y вокруг центра юнита);
  ⚠️ бить может ТОЛЬКО блок, реально упавший ≥ `ROCKFALL_MIN_FALL`(0.15 тайла) — иначе срыв бил на
  КАДРЕ ОТРЫВА (vy=0, камень визуально на месте), если юнит подлезал под дрожащий камень.
  Удар В ПОЛЁТЕ (перекрытие тел) — намеренно: иначе валун пролетал бы сквозь висящего юнита.
  Нестабильная при ударе — осколки (`_shatter`→`debris`) и пропадает; валун — `world.settleRock`
  ЗАНИМАЕТ клетку (снова порода, может упасть опять) + `unit.shove` отталкивает юнита.
- Рендер летящих/осколков — `drawFalling` ПОВЕРХ тумана (опасность всегда видна).

## Пещеры-сцены (backdrops)

`genBackdrops` → `this.backdrops` = `BACKDROP_COUNT`(=3) больших эллипс-полостей ниже города
(`{cx,cy,rx,ry,kind,seed,scanned,scanning,sweepT,reveal}`, kind city/machine/idol, разнос по тору;
вырезаются как AIR, исключены из спавна серверов). Вход юнита → объёмный скан
(`game.updateBackdrops`: свип `BACKDROP_SWEEP`=4.5с → `_backdropDone`: `BACKDROP_DATA`=2 фрагмента
в кодекс + глоссарий + лог).

Рендер (`render_backdrop.js`): сцена ПОВЕРХ тумана, клип по `clipVisibleAir` И эллипсу полости.
Главный объект — растровый ассет `assets/junk/old_robot.png` (`_bdRobot`, `new Image()` → работает
на file://): вписан по ширине пещеры (~135%), низ ЧУТЬ НИЖЕ дна полости («стоит» на дне), паралакс
слоёв от смещения юнита; точный прямоугольник отрисовки стэшится в `b._astRect`, центр — в
`b._astX/_astY/_astR` (туда целится конус сканера `render_scan.drawBackdropScan`). Свип-полоса
`_bdSweep` МАСКИРОВАНА по ассету: в полосе ассет перерисовывается в `lighter` → подсвечиваются
только непрозрачные пиксели (фолбэк до загрузки — cobalt-полоса по эллипсу). Фолбэк-объект —
процедурный по `kind` (`_bdKind`).
