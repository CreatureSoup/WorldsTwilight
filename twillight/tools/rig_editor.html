RIG EDITOR

Проект

Снимок юнита (блупринт + ассеты) в JSON. «→ В ИГРУ» кладёт настроенного юнита в localStorage — игра подхватит его на старте забега (тот же origin). «стереть» убирает.

Поза / направление

Модули (отсоединение)

Выключи — деталь с `need` и её кабель исчезают, как в мире при снятии.

Бур-щит (составной)

Отделяемый проходческий щит винтового бура — ДВЕ части: КРЕПЛЕНИЕ (сзади) + БУР-ЩИТ (спереди). Жми «превью» на любой карточке → в слот бура встаёт ВИНТОВОЙ и составной щит рисуется НА СБОРКЕ (торчит из корпуса по взгляду, как в игре); ассеты при наличии, иначе процедурный фолбэк. Канонический кадр — «вперёд» = вправо (+X). Экспорт — `module_assets.js` (ключи `borer:mount`/`borer:shield`). ⚠️ у варианта бура «винтовой» СВОЕЙ спрайт-подмены детали нет (иначе дублировал бы щит) — вид авторится ТОЛЬКО здесь.

Спрут: щупальце-якорь (составное)

Якорные щупальца «Спрута» — ДВЕ части: ЗВЕНО (тиражируется вдоль прямой ноги, канонический кадр — «вдоль ноги» = вправо +X) + ЯКОРЬ-ЛАПА (наконечник-хват, смотрит от корпуса = вправо +X). Жми «превью» → корпус переключается на «sprut», живые якоря цепляются к линейке пол/потолок. КРЕПЛЕНИЯ ног — детали kind:anchor в списке деталей (тяни ручки по кругу, ang/rad). Ключи ГЛОБАЛЬНЫЕ: `sprut:link`/`sprut:claw`.

Канонир: колесо (составное)

Моно-колесо «Канонир» — ДВЕ части: КОРПУС-КОЛЬЦО (основной каркас, НЕДВИЖНО+ОТЦЕНТРОВАНО — рисуется по центру без поворота) + КОЛЬЦО-ЗУБЬЯ (встроенный бур, ВРАЩАЕТСЯ по ходу/бурению). Жми «превью» → корпус переключается на «gun», колесо рисуется НА СБОРКЕ; ассеты при наличии, иначе процедурно. Канонический кадр — обе части ЦЕНТРИРОВАНЫ. Экспорт — `module_assets.js` (глоб. ключи `wheel:body`/`wheel:tooth`). ⚠️ РЕАКТОР-ядро и ТУРЕЛЬ (ствол+купол по +X) — обычные детали блупринта (список деталей, ключи `gun:reactor`/`gun:turret`), не здесь.

Детали

Ноги (kind:leg) — экранно снизу, не крутятся с корпусом; «зеркало» даёт вторую ногу пары. У каждой ноги своя карточка ассета.

Кабели (мускулы)

Один ассет на все кабели: тянется по длине A→B, задний слой.

idle-качание массы

Экспорт

ассеты вариантов модулей (из карточек деталей)
