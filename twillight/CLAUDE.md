## 1. Проект

**Twilight of the World (Сумерки мира)** — roguelite-копалка, вид сбоку, с гравитацией.
Игрок-ИИ через базу-принтер управляет ботом-буром. Дизайн-источник — `gdd_mvp_v0.4.md`.

**Стек:** чистый HTML + JS + Canvas 2D. **Без npm, сборщиков, фреймворков.** Открывается
двойным кликом по `index.html` (file://) или превью-сервером. Главный цикл — rAF.

**Что уже есть:** тор-мир со стратами (тёплые вверх — погребённая цивилизация, холодные вниз —
«космос»), юнит-кольцо на IK-щупальцах (копание/клинг/гравитация), города и гибернация, враги
диких гнёзд (копатель/собиратель/рейдер) с циклами-волнами, скан данных → кодекс с глоссарием,
мета-прогресс (МЕГА-ТОКЕНЫ + СЕТЬ ПАМЯТИ), сборка юнита, апгрейды сессии, localStorage-сейв.

## 2. Запуск и проверка

- **Запуск:** `index.html` двойным кликом, либо статик-сервер из `.claude/launch.json` (порт 8123).
- **После КАЖДОГО изменения проверяй в браузере** (preview): скриншот ключевых экранов +
  `preview_console_logs` (ошибок быть не должно).
- **rAF в превью тормозит** между «тихими» eval-вызовами (фоновая вкладка). Логику проверяй
  детерминированно — шагай симуляцию вручную:
  ```js
  game.input.keys = new Set(['KeyS']);
  for (let i=0;i<120;i++) game.unit.update(1/60, game.input, game.world);
  game.input.keys = new Set();
  ```
  Либо форсни кадр скриншотом/resize (будит цикл).
- **Окно превью иногда схлопывается в 1px** — чини `preview_resize` (например 980×1000).
- **`?v=Date.now()` бьёт кэш только у JS, НЕ у самого `index.html`.** Добавил файл в загрузчик —
  браузер может отдать старый html без нового `<script>`: функции будут `undefined` БЕЗ ошибки.
  Лечение: `location.href='/index.html?cb='+Date.now()`.
- `window.game` — точка входа для отладки. **Дебаг-обзор — клавиша B** (свободная камера, туман
  выкл, юнит заморожен, мир живёт, маркеры объектов видны).

## 5. Архитектура: один тип сущностей — один файл

**Не наращивай `game.js`** — новую подсистему клади в свой файл (логика отдельно, рендер —
свободные функции `draw*` в `render_*.js`) и допиши `<script>` в правильное место загрузчика.
Детали системы — в её `spec_*.md`; сюда — только строка таблицы + ссылка.

## 6. Правила кода

- **Логика отдельно от рендера.** `update(dt,…)` без Canvas; `draw(…)` не меняет состояние.
- **Ввод — по `e.code`** (раскладко-независимо), не по `e.key`.
- **rAF, `dt` в секундах, клампить** (`dt = min(dt, 0.05)`); скорости — в ед/сек × dt.
- **Никаких магических чисел по коду** — именованные константы в `constants.js`.
- **UI-тексты — по-русски.** Идентификаторы — латиницей.
- **Комментарии — только ПОЧЕМУ** (инвариант, причина), не ЧТО. По умолчанию — без комментариев.
- **Без преждевременных абстракций**, мёртвого кода, полуреализаций.
- Маленькие функции, явные имена, без скрытых сайд-эффектов.
